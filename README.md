## 📖 About

🔹 **Terraria — Split** is a powerful tool built to help you play Terraria in split-screen mode with another player on the same PC or monitor. Split enables local co-op in Terraria by dividing the screen into separate viewports for two simultaneous players.

🔸 Whether you're a seasoned professional or just getting started, **Terraria — Split** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Terraria modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Split Screen | Divide the display into two independent game viewports |
| Independent Cameras | Each player controls their own camera position freely |
| Controller Support | Works with two gamepads for a true couch co-op experience |
| Server Optional | Play locally without the need for a network or Hamachi connection |
